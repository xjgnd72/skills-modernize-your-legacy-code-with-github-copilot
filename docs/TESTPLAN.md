# COBOL Account Management System Test Plan

このテスト計画は、`src/cobol` にある現行 COBOL アプリケーションの業務ロジックと実装動作を、業務ステークホルダーが確認するためのものです。各テストは独立して実行する場合、プログラムを再起動して初期残高 `1000.00` に戻してください。

| TC-002 | メニューが4つの操作を提供することを確認する | アプリケーションを起動できる | 1. アプリを起動する。 | View Balance、Credit Account、Debit Account、Exit、および選択入力の案内が表示される。 |  |  |  |

## Stakeholder Decisions To Capture

- ゼロおよび負数の入金・出金を業務上許可するか。
- 金額が `999999.99` を超える場合のエラー動作と業務上限。
- アプリ終了後も残高を永続化する必要があるか。
- Node.js 移行後も単一の共有口座を維持するか、顧客・学生ごとの口座に分離するか。
- 実際の画面表示で必要な金額フォーマット（先頭ゼロ、通貨記号、小数桁）を確定する。
